# Liri Media Player

Media Player für **Android TV, Fire TV und Android** (Handy/Tablet).

## Herunterladen

**Neueste Version (APK):**
https://github.com/LiriPlayer/liri-releases/releases/latest/download/Liri.apk

### Fire TV
1. Im Amazon-Store die App **Downloader** installieren.
2. Einstellungen → Mein Fire TV → Entwickleroptionen → **Unbekannte Apps installieren** → Downloader erlauben.
3. In Downloader den Link oben eingeben → **Installieren**.

### Android TV / Handy
Link oben im Browser öffnen, Datei öffnen und **Installieren** (beim ersten Mal das Installieren aus dieser Quelle erlauben).
